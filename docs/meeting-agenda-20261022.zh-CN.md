# 导师交流提纲

**日期：** 2026 年 10 月 22 日  
**状态：** 以下为待讨论问题和建议要求，尚未确认。

## 1. 接盘成功的定义

- [ ] 成功空中接盘是否定义为：飞盘首次落地前，被狗用嘴接住？
- [ ] 如果狗在飞盘落地前接住，但立即脱口掉落，是否仍算成功接盘？
- [ ] 落地捡盘（飞盘先落地，狗再叼起）是否与空中接盘分开统计？

## 2. 双视角与不确定结果

- [ ] 是否必须同时提供正面和侧面视频，还是也允许单个固定视角？
- [ ] 遮挡、飞盘出画或证据不足时，即使有双视角，是否允许输出 `uncertain`？
- [ ] uncertain 事件是否从接盘率分母中排除，并单独报告？

## 3. 视频规格

- [ ] 是否认可以下初期建议？

| 项目 | 建议规格 |
| --- | --- |
| 文件大小 | 单文件不超过 500 MB |
| 分辨率 | 优先 1080p |
| 帧率 | 优先 60 fps |
| 封装格式／编码 | 优先 MP4／H.264 |
| 视频时长 | 初期每段 30–60 秒连续短片，便于验证 |

- [ ] 是否还必须支持 30 fps、4K 和 HEVC 视频？
- [ ] 如果原视频超限，是否允许拆分为连续短片，同时保证每段包含完整投掷及其结果？

## 4. 拍摄要求

- [ ] 本阶段是否可以明确要求固定三脚架，暂不支持手持或跟拍？
- [ ] 是否可以要求尽量完整覆盖投掷、飞盘飞行、狗与飞盘接触及接触后的动作？
- [ ] 双视角是否可以同时录制同一次训练，并提供同步参考？

## 5. 页面与交付范围

- [ ] 现有统计、事件回放和 `uncertain` 提示是否足够？还需要修改什么？
- [ ] 是否需要人工确认或纠正机器结果？
- [ ] 本阶段是否接受“线上界面原型＋本地完整分析系统”？

## 6. 视频使用、云端处理与隐私授权

- [ ] 不允许上传 GitHub，是指不能公开发布视频，还是不能上传任何第三方平台？
- [ ] 是否允许上传到私有云端进行临时分析，并在处理完成后删除原视频？
- [ ] 是否允许保留报告、缩略图、截图或压缩预览？仅限授权用户查看，还是允许公开演示？
- [ ] 各类数据允许保存多久，由谁访问，并由谁负责删除？

**说明：** 云端视频分析通常仍需传输视频或抽帧，即使不永久保存。缩略图和预览仍可能展示人物或场景，其使用需要另行确认。如果视频不能离开本机，视频分析也应在本地运行，云端只接收明确获准的报告数据。

请老师协助与视频提供方确认，并记录授权范围。GitHub 仅保存代码及获准公开的文档。
